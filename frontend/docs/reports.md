# Спецификация: страница «Отчёты» студента (Тестовая часть)

**Версия:** 1.0  
**Дата:** 27.11.2026  
**Роль:** Студент  
**Статус документа:** согласовано для разработки

---

## 1. Назначение страницы

Страница «Отчёты» — экран аналитики и отслеживания прогресса студента. Здесь студент видит сводную информацию по всем выполненным заданиям, чтобы оценивать свою динамику, понимать, какие темы даются лучше, а какие хуже, и видеть прогресс в подготовке к экзамену.

В текущей версии (v1.0) страница покрывает только **тестовую часть** заданий (автопроверка). Устно-письменная часть с ручной/ИИ оценкой будет добавлена отдельной задачей.

---

## 2. Структура и навигация

### 2.1. Точка входа
Страница доступна по отдельному пункту нижнего меню «Отчёты» (`/student/reports`).

### 2.2. Вкладки (Табы)
На странице есть два таба для переключения типа отчёта:
1. **Обычные задания** (активен по умолчанию).
2. **Экзамен**.

Если студент не решал заданий соответствующего типа, показывается дружелюбное пустое состояние (см. раздел 6).

### 2.3. Фильтр периода
Над таблицей расположены чипы-вкладки для выбора периода:
- **Месяц** (текущий календарный месяц).
- **Год** (текущий учебный год: с 1 сентября по 31 августа). **Активен по умолчанию.**
- **Всё время** (все доступные данные).

---

## 3. Вкладка «Обычные задания»

Отображает сводную таблицу по всем обычным заданиям (GAP_FILL, WORD_FORMATION и т.д.), которые не помечены флагом `isExam`.

### 3.1. Группировка и сортировка
- **Верхний уровень:** Группировка по месяцам.
- **Сортировка:** От новых к старым (сверху текущий месяц, внизу более ранние).
- **Внутри месяца:** Задания сгруппированы по типу механики и теме. Если одно и то же задание решалось несколько раз в течение месяца, даты и результаты перечисляются списком внутри одной строки.

### 3.2. Структура таблицы
| Месяц | Тип задания | Тема | Уровень | Дата | Результат | Средний % |
|---|---|---|---|---|---|---|
| **Ноябрь** | GAP_FILL | Present Simple | A1 | 06.11 | 2/3 | **67%** |
| | | | | 24.11 | 3/3 | |
| | WORD_FORMATION | Family | A2 | 24.11 | 2/3 | **67%** |
| **Октябрь** | GAP_FILL | Past Simple | A2 | 12.10 | 1/3 | **33%** |

*Примечание: Колонка «Средний %» объединяет ячейки по вертикали для всего месяца и показывает средний процент правильных ответов по всем заданиям за этот месяц.*

### 3.3. Математика (Агрегаты на бэке)
- **Результат:** Дробь `правильных_пунктов / всего_пунктов`.
- **Средний % за месяц:** Среднее арифметическое процентов выполнения всех заданий за месяц.
  *(Пример: Задание 1 = 2/3 (66.6%), Задание 2 = 3/5 (60%). Средний % = (66.6 + 60) / 2 = 63%).*

---

## 4. Вкладка «Экзамен»

Отображает сводную таблицу по заданиям, помеченным флагом `isExam = true`.

### 4.1. Группировка и сортировка
- Аналогично обычным заданиям: группировка по месяцам, сортировка от новых к старым.
- Внутри месяца задания группируются по **Номеру задания ЕГЭ** (например, все попытки №37 в одной группе, все попытки №40 в другой).

### 4.2. Структура таблицы
| Месяц | № ЕГЭ | Тип задания | Макс. балл | Дата | Балл | Средн. балл |
|---|---|---|---|---|---|---|
| **Ноябрь** | №37 | Личное письмо | 6 | 06.11 | 4 | **5.0** |
| | | | | 12.11 | 6 | |
| | №40 | Условный диалог | 4 | 24.11 | 3 | **3.0** |
| | **Итого за месяц:** | | | | | **8.0** |
| **Октябрь** | №40 | Условный диалог | 4 | 12.10 | 2 | **2.0** |
| | **Итого за месяц:** | | | | | **2.0** |

### 4.3. Математика (Агрегаты на бэке)
- **Балл:** Первичный балл по шкале ФИПИ (не количество верных пунктов, а именно итоговый балл за попытку).
- **Средн. балл:** Среднее арифметическое первичных баллов **внутри одного типа задания** (например, средний балл только по №37 за ноябрь).
- **Итого за месяц:** Сумма средних баллов по всем типам заданий за месяц. *(Пример: Средний по №37 = 5.0, средний по №40 = 3.0. Итого = 8.0).*

---

## 5. Детализация (Drill-down)

- **Кликабельные элементы:** В обеих вкладках кликабельна **конкретная дата** (конкретная попытка).
- **Действие:** При клике на дату студент переходит на существующую страницу детального отчёта (`/student/work/{workId}/report`), где видит текст задания, свои ответы, эталоны и попытки.
- **Ограничение:** Вся строка целиком не кликабельна, так как в одной ячейке может быть несколько дат, ведущих на разные отчёты.

---

## 6. Пустые состояния и ошибки

- **Общее пустое состояние:** Если за выбранный период (Месяц/Год/Всё время) нет ни одного выполненного задания, показывается сообщение: *«За этот период заданий не было»*.
- **Пустое состояние вкладки «Экзамен»:** Если студент вообще никогда не решал экзаменационных заданий (флаг `isExam`), при переключении на эту вкладку показывается специфичное сообщение: *«Вы ещё не решали экзаменационные задания. Здесь будет отображаться ваш прогресс по заданиям формата ЕГЭ»*.
- **Ошибки загрузки:** При сетевой ошибке показывается стандартное сообщение *«Ошибка загрузки данных»* и кнопка «Повторить».

---

## 7. Разделение ответственности (Frontend vs Backend)

- **Backend:** Отдаёт полностью агрегированные данные. Бэкенд сам группирует задания по месяцам, считает средние проценты (для обычных), средние первичные баллы и суммы за месяц (для экзаменов). Фронтенд получает готовую древовидную структуру для рендера.
- **Frontend:** Отвечает только за отрисовку таблицы, переключение табов, применение фильтра периода (передаёт выбранный период на бэк) и обработку кликов по датам.

---

## 8. Критерии приёмки

1. [ ] Страница доступна из нижнего меню «Отчёты».
2. [ ] По умолчанию открыта вкладка «Обычные задания» и выбран период «Год» (текущий учебный год).
3. [ ] Таблица обычных заданий сгруппирована по месяцам (от новых к старым), внутри месяца — по типу и теме.
4. [ ] Для обычных заданий корректно считается и отображается «Средний %» за месяц.
5. [ ] Таблица экзаменационных заданий содержит колонки «№ ЕГЭ», «Макс. балл», «Балл», «Средн. балл» и «Итого за месяц».
6. [ ] Для экзаменационных заданий «Итого за месяц» равно сумме средних баллов по каждому типу задания.
7. [ ] Клик по конкретной дате в таблице открывает страницу детального отчёта по этой попытке.
8. [ ] При отсутствии данных отображаются корректные дружелюбные сообщения (общее и специфичное для вкладки «Экзамен»).
