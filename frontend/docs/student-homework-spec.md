# Спецификация: страница «Домашние задания» студента

**Версия:** 1.0
**Дата:** 26.11.2026
**Роль:** Студент
**Статус документа:** согласовано для разработки

---

## 1. Назначение страницы

Страница «Домашние задания» — главный рабочий экран студента. Здесь студент видит все задания, которые ему назначил учитель, и управляет их выполнением.

Страница закрывает три потребности студента:

1. Понять, **что нужно сделать сегодня** и в ближайшее время.
2. Проверить, **что уже сдано**.
3. **Найти старое задание** — например, то, что решал на прошлой неделе или в прошлом месяце.

В текущей версии страница предназначена только для студента. Отображение этого же списка глазами учителя будет добавлено отдельной задачей.

---

## 2. Жизненный цикл задания и статусы

Каждое задание находится в одном из пяти статусов. Статус определяется системой автоматически — по действиям студента и по дате дедлайна. Учитель и студент не могут менять статус вручную.

### 2.1. Что означает каждый статус

| Статус | Когда задание получает этот статус | Смысл для студента |
|---|---|---|
| **Новое** | Учитель назначил задание недавно (не более 14 дней назад), студент его ещё не открывал, и дедлайн наступит не скоро (более чем через 14 дней). | «Свежее задание, времени много, можно сделать позже». |
| **Скоро дедлайн** | Дедлайн наступит в течение 14 дней (включая сегодня). Сюда же попадают старые назначенные задания, которые студент так и не начал. | «Пора делать, времени мало». |
| **В процессе** | Студент открыл задание и начал его выполнять. Отдельного режима «просто посмотреть» нет: сам факт открытия означает начало работы. | «Я уже работаю над этим». |
| **Выполнено** | Студент ответил на все пункты задания. Отдельного подтверждения от учителя не требуется — сдал все пункты, значит выполнено. | «Готово, можно забыть». |
| **Просрочено** | Наступил дедлайн, а задание не выполнено. Присваивается автоматически. Вручную просрочить нельзя. | «Не успел, задание закрыто». |

### 2.2. Как статусы переходят друг в друга

Переходы возможны только вперёд, возврата назад нет (например, из «В процессе» обратно в «Новое» задание вернуться не может).

**Основные переходы:**

- Новое → В процессе (студент начал выполнять)
- Скоро дедлайн → В процессе (студент начал выполнять)
- В процессе → Выполнено (студент сдал все пункты)
- В процессе → Просрочено (дедлайн прошёл, задание не доделано)
- Новое → Просрочено (дедлайн прошёл, студент не начал)
- Скоро дедлайн → Просрочено (дедлайн прошёл, студент не начал)

### 2.3. Цветовое оформление

Каждый статус имеет собственный цвет бейджа, чтобы студент считывал состояние одним взглядом. Точные цвета задаются в дизайн-системе.

### 2.4. Задания без дедлайна

Учитель может назначить задание без дедлайна. Такие задания обязательно должны быть видны студенту.

Правило: у задания без дедлайна нет срочности и нет просрочки. Поэтому оно **никогда** не попадает в статусы «Скоро дедлайн» и «Просрочено». Такое задание остаётся «Новым», пока студент его не начнёт, затем ведёт себя как обычное: «В процессе» → «Выполнено». Это гарантирует, что ни одно задание без дедлайна не «потеряется» в фильтрах.

## 3. Фильтры

Над списком расположены чипы-фильтры: **Все · Новое · Скоро дедлайн · В процессе · Выполнено · Просрочено**. Выбор фильтра показывает только задания в соответствующем статусе (по правилам из раздела 2).

### 3.1. Фильтр по дате

Дополнительный выбор периода доступен **только для двух статусов**:

- **Выполнено** — по **дате сдачи** (когда студент ответил на последний пункт). Позволяет найти, что решал на прошлой неделе или в прошлом месяце.
- **Просрочено** — по **дате дедлайна** (когда нужно было сдать). Позволяет найти, что было просрочено в выбранном периоде.

Для статусов **Новое, Скоро дедлайн, В процессе** отдельный выбор даты **недоступен**. Причина: временной смысл уже встроен в сам статус (например, «Новое» — это «назначено не более 14 дней назад»). Добавлять к этому ещё один выбор даты логически бессмысленно — студент не ищет «новое задание за прошлый месяц», потому что месяц назад назначенное задание уже не новое.

### 3.2. Готовые пресеты периода

Для «Выполнено» и «Просрочено» студент может выбрать период: **Сегодня · За неделю · За месяц · Произвольный диапазон** (выбор дат вручную). Произвольный диапазон должен корректно применяться к выбранному статусу.

## 4. Карточка задания

Каждое задание в списке показано карточкой. В карточке есть:

- **Название** задания (если названия нет — публичный идентификатор, например `TSK-1`).
- **Бейдж статуса** (цветной, см. 2.3).
- **Дедлайн** («до 20 ноября») либо «Без дедлайна», если дата не задана.
- **Тематические чипы** — краткое описание задания: тип упражнения (например, `GAP_FILL`, `WORD_FORMATION`), уровень сложности (например, `A1`, `A2`), грамматическая тема (например, `Present Simple`), лексическая тема (например, `Family`).
- **Прогресс** — сколько пунктов выполнено из общего числа (например, «0 / 3»). Пункты (предложения/подзадачи) создаёт учитель при создании задания.

---

## 5. Взаимодействие со списком

- **Клик по карточке.** Если задание «Новое», «Скоро дедлайн» или «В процессе» — студент переходит к выполнению (статус «Новое»/«Скоро дедлайн» при этом становится «В процессе»). Если «Выполнено» или «Просрочено» — задание закрыто, к выполнению не переходит.
- **Действия прямо в списке.** Студент не может выполнить задание «галочкой» из списка или совершить иное действие, не заходя внутрь. Все действия — только внутри карточки.

---

## 6. Пагинация и пустое состояние

- Список разбивается на страницы (по умолчанию 10 заданий на странице), переключение — внизу.
- Если заданий нет или ни одно не подходит под фильтр, показывается дружелюбное сообщение: «Нет заданий».

---

## 7. Что должно храниться о задании для корректной работы

Чтобы статусы и фильтры считались правильно, по каждому назначению нужны: дата назначения, дата дедлайна (может отсутствовать), дата начала выполнения, дата сдачи, общее число пунктов и число выполненных пунктов.

---

## 8. Критерии приёмки

1. Студент видит все свои индивидуальные задания в корректных статусах.
2. Статусы определяются автоматически и меняются только по правилам раздела 2.2.
3. Фильтр по дате работает только для «Выполнено» (по дате сдачи) и «Просрочено» (по дате дедлайна); для остальных статусов недоступен.
4. Произвольный диапазон дат корректно применяется для «Выполнено» и «Просрочено».
5. Карточка показывает название, бейдж, дедлайн, тематические чипы и прогресс.
6. Задания без дедлайна видны и никогда не становятся «Скоро дедлайн» или «Просрочено».
7. Клик по незакрытому заданию начинает выполнение.
8. При отсутствии заданий показывается сообщение «Нет заданий».
