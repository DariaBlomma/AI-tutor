# План: Исправление обновления прогресса после submit

## Проблема
После решения пункта класс `done` не появляется на предыдущем пункте сразу — только после обновления страницы.

## Причина
`solvedItems` вычисляется из `workDetail.progress`, который берётся из React Query кэша. После `submitMutation.onSuccess` кэш не обновляется — он обновляется только при следующем запросе (обновление страницы).

## Решение
Обновить `workDetail` в кэше React Query после успешного submit через `queryClient.setQueryData`.

## Изменения

### `src/student/hooks/useWorkExecution.ts`
В `submitMutation.onSuccess` добавить обновление кэша:

```ts
queryClient.setQueryData(['student', 'work', workId], (old: StudentWorkDetailResponse | undefined) => {
    if (!old) return old;
    return {
        ...old,
        progress: old.progress.map((p) =>
            p.taskItemId === response.taskItemId
                ? { ...p, status: response.status as ItemProgressStatus }
                : p,
        ),
    };
});
```

## Верификация
1. `npm run build` — без ошибок
2. Протестировать: решить пункт → проверить, что на предыдущем пункте появляется галочка сразу
