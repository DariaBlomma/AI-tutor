# План: Мобильное нижнее меню → десктопный сайдбар

## Цель
На экранах **≥1024px** заменить нижнее меню на левый сайдбар с возможностью сворачивания до иконок (~60px). На **<1024px** — нижнее меню без изменений.

## Требования
- Сайдбар: виден по умолчанию (240px), сворачивается до иконок (60px)
- Состояние сворачивания сохраняется в `localStorage`
- Без анимации при сворачивании/разворачивании
- Без новых зависимостей (использовать существующие: React, TanStack Router, SCSS)
- Переиспользовать `APP_BOTTOM_NAV_ITEMS`, типы и иконки

## Реализация

### Шаг 1: `useSidebar` hook

**Файл**: `src/shared/hooks/useSidebar.ts`

Хук управляет состоянием `collapsed` с персистентностью в `localStorage`:
- `collapsed` — boolean
- `toggle()` — переключить
- `collapse()` / `expand()` — явные методы
- Lazy init из localStorage при монтировании
- try/catch на localStorage (private browsing)

### Шаг 2: `AppSidebar` widget

**Файл**: `src/shared/widgets/AppSidebar/AppSidebar.tsx`

Компонент сайдбара:
- `<aside>` с классами `.sidebar` / `.sidebar.collapsed`
- Кнопка toggle с inline SVG chevron (направление зависит от состояния)
- Навигация через `<Link>` из TanStack Router
- Переиспользует `APP_BOTTOM_NAV_ITEMS` напрямую
- При `collapsed` — скрывает `<span>` с лейблами, иконки остаются
- Активный пункт подсвечивается (purple accent)

**Файл**: `src/shared/widgets/AppSidebar/AppSidebar.module.scss`

```scss
.sidebar {
    position: fixed; top: 0; left: 0; height: 100vh;
    width: 240px; background: var(--bg);
    border-right: 1px solid rgba(157, 124, 242, 0.2);
    display: flex; flex-direction: column; z-index: 200;
    transition: none; // без анимации
}
.collapsed { width: 60px; }
.toggleButton { /* кнопка chevron, 48px высота */ }
.navItem { /* flex, gap 12px, padding 10px 16px, border-radius 8px */ }
.active { color: var(--p); background: rgba(157, 124, 242, 0.12); }
.navIcon { width: 24px; height: 24px; flex-shrink: 0; }
.navLabel { font-size: 14px; font-weight: 500; }
```

### Шаг 3: Модификация `LayoutRoot`

**Файл**: `src/shared/layouts/LayoutRoot.tsx`

Добавить `useIsDesktop` хук (через `window.matchMedia` + listener):
- `≥1024px` → рендерит `AppSidebar`
- `<1024px` → рендерит `AppBottomNav` (как сейчас)

Добавить эффект для класса на `body`:
```tsx
useEffect(() => {
    const collapsed = localStorage.getItem('app-sidebar-collapsed') === 'true';
    document.body.classList.toggle('sidebar--collapsed', collapsed);
}, [isDesktop]);
```

### Шаг 4: Стили для `main`

**Файл**: `src/shared/styles/global.scss`

```scss
.main--with-sidebar { margin-left: 240px; }
body.sidebar--collapsed .main--with-sidebar { margin-left: 60px; }
```

## Верификация

1. `npm run build` — без ошибок TS и SCSS
2. **Desktop (≥1024px)**:
   - Сайдбар виден по умолчанию с иконками + лейблами
   - Toggle → сворачивается до иконок (60px), контент сдвигается
   - Reload → состояние сохраняется
   - Активный пункт подсвечен
   - Hover/active состояния работают
3. **Mobile (<1024px)**:
   - Нижнее меню появляется, сайдбар исчезает
   - Навигация работает
4. **Role-based**: Student → «Банк заданий» скрыт в обоих видах
5. **Auth routes**: Сайдбар не появляется на `/auth/*`
