## Детали реализации

### Кнопка фильтров (мобильная)
- Иконка фильтра (SVG) в header row справа от заголовка «Банк заданий»
- Видна только на мобильных (`@media (min-width: 1024px) { display: none; }`)
- Клик → toggle `filtersOpen`

### Overlay
- Fixed overlay на весь экран с затемнением (rgba(0,0,0,0.4))
- Появляется при `filtersOpen=true` на мобильных
- Клик по overlay → закрыть фильтры

### Mobile Sidebar
- Fixed position, left: 0, top: 0, height: 100vh
- Ширина ~300px (как десктопный 280px + padding)
- Transform: translateX(-100%) в закрытом состоянии, translateX(0) в открытом
- Transition: transform 0.25s ease
- Содержит те же `<TasksBankFilters>` с теми же props
- Values сохраняются (state в TasksBankView не сбрасывается)

### Desktop
- Полностью без изменений: CSS Grid 280px sidebar + content

## Верификация
- На мобильных (<1024px): фильтры скрыты, есть кнопка с иконкой фильтра → sidebar выезжает слева, overlay затемняет фон, клик по overlay закрывает
- Значения фильтров сохраняются при открытии/закрытии
- На десктопе (≥1024px): без изменений, sidebar виден как раньше
