# План: Страница ДЗ для ученика (`/student/homework`)

## Контекст

Новая вкладка «ДЗ» для ученика с дизайном:
- Фильтр-чипы: Все / Новое / В процессе / Выполнено / Просрочено
- DateTimePicker для фильтрации по deadline (пресеты на фронте + диапазон)
- Карточки работ с прогресс-баром
- Пагинация (как в taskBankView)
- Bottom navigation

## Архитектурные решения

| Решение | Выбор |
|---------|-------|
| Маршрут | `/student/homework` |
| Фильтрация по deadline | Фронт: пресеты + диапазон. Бэк: `deadlineFrom` + `deadlineTo` query params |
| Прогресс | Добавить `completedItems`/`totalItems` в ответ `GET /student/work` |
| Пагинация | Существующий `Pagination` + паттерн `useTasksBank` |
| Стили | CSS Modules (`.module.scss`) |
| API | React Query (`@tanstack/react-query`) |

### 2.2. Обновить сервис

```typescript
export interface HomeworkFilters {
    page: number;
    size: number;
    status?: WorkStatus;
    deadlineFrom?: string | null;
    deadlineTo?: string | null;
    sortBy?: 'deadline' | 'status' | 'createdAt';
    sortDirection?: 'asc' | 'desc';
}

getWorks(filters: HomeworkFilters): Promise<StudentWorkPage> {
    const params = new URLSearchParams();
    params.append('page', String(filters.page));
    params.append('size', String(filters.size));
    if (filters.status) params.append('sort', filters.status);
    if (filters.sortBy) params.append('sort', filters.sortBy);
    if (filters.sortDirection) params.append('direction', filters.sortDirection);
    if (filters.deadlineFrom) params.append('deadlineFrom', filters.deadlineFrom);
    if (filters.deadlineTo) params.append('deadlineTo', filters.deadlineTo);
    
    return this.http.get(`/student/work?${params.toString()}`);
}
```

## Этап 3: Фронтенд — утилиты и хуки

### 3.1. Пресеты для фильтрации по дате

**Файл:** `frontend/src/student/lib/datePresets.ts`

```typescript
export type DatePreset = 'all' | 'today' | 'week' | 'month' | 'custom';

export interface DateRange {
    from: string | null;
    to: string | null;
}

export function getDateRange(preset: DatePreset): DateRange {
    const now = new Date();
    const startOfDay = new Date(now.getFullYear(), now.getMonth(), now.getDate());
    
    switch (preset) {
        case 'today':
            return { from: startOfDay.toISOString(), to: now.toISOString() };
        case 'week': {
            const weekStart = new Date(startOfDay);
            weekStart.setDate(startOfDay.getDate() - startOfDay.getDay());
            return { from: weekStart.toISOString(), to: now.toISOString() };
        }
        case 'month': {
            const monthStart = new Date(now.getFullYear(), now.getMonth(), 1);
            return { from: monthStart.toISOString(), to: now.toISOString() };
        }
        default:
            return { from: null, to: null };
    }
}
```
