# План: унификация карточек заданий на дашборде и странице ДЗ

## Контекст

На дашборде и странице ДЗ используется один компонент, но данные приходят по-разному:
- **Дашборд**: `useStudentDashboard` → `mapToStudentWorkCard()` → `StudentWorkCard`
- **Страница ДЗ**: inline-маппинг прямо в `StudentHomeworkView` (строки 62-76)

Задача: убрать дублирование маппинга, переместить компонент в `tasks/ui/base/`, переименовать модель.

**Названия моделей:**
- `StudentWorkResponse` — сырой DTO с API (содержит `completedItems`, `totalItems`, `startedAt`)
- `StudentWorkCard` — модель для отображения карточки в UI (без служебных полей)

## Риски и нюансы

1. **`completedAt`** в `StudentWorkCard` не маппится из `StudentWorkResponse` — нужно добавить
2. **`teacherName`** в `StudentWorkCard` есть в типе, но нигде не используется в компоненте — можно оставить `undefined`
3. **Зависимости между модулями**: `tasks/ui/base/` будет импортировать из `student/ui/components/StatusBadge` — это создаёт обратную зависимость `tasks → student`. Нужно проверить, допустимо ли это в архитектуре проекта.
   - **Альтернатива**: вынести `StudentStatusBadge` в `shared/ui-kit/` или в `tasks/ui/base/`
4. **`StudentHomeworkItem`** (legacy, `../../src/student/ui/base/StudentHomeworkItem`) — не используется нигде, можно удалить заодно
