### 3. Service: синхронизация курсов в TaskService

**Файл:** `backend/src/main/java/com/aitutor/backend/services/task/TaskService.java`
- Внедрить `CourseService` через конструктор
- Добавить `@Autowired` (или final field) `CourseTaskRepository`
- В методе `create()` — после `taskRepository.saveAndFlush(task)` вызвать `courseService.syncTaskCourses(task.getId(), request.getCourseIds(), teacherId)`
- В методе `update()` — перед `return taskMapper.toResponse(task)` вызвать `courseService.syncTaskCourses(id, request.getCourseIds(), teacherId)`
- В `getById()` и `getByPublicId()` — после маппинга заполнить `response.setCourseIds(...)` из `CourseTaskRepository.findCourseIdsByTaskId(teacherId, taskId)`

### 4. Service: метод синхронизации курсов в CourseService

**Файл:** `backend/src/main/java/com/aitutor/backend/services/course/CourseService.java`
- Добавить метод `Set<Long> getCourseIdsForTask(Long taskId, Long teacherId)` — возвращает список id курсов, где есть задание
- Добавить метод `void syncTaskCourses(Long taskId, Set<Long> targetCourseIds, Long teacherId)` в `@Transactional`
  - Логика:
    1. Найти все курсы, где задание уже есть (`courseTaskRepository.findByTaskId(taskId)`)
    2. Удалить из курсов, которых нет в `targetCourseIds`
    3. Добавить в курсы из `targetCourseIds`, которых ещё нет (position = конец через `resolvePosition(null, size)`)

### 4. Controller: использовать синхронизацию

**Файл:** `backend/src/main/java/com/aitutor/backend/controllers/TaskController.java`
- `TaskService.create()` — после создания задания вызвать `courseService.syncTaskCourses(taskId, request.getCourseIds(), teacherId)`
- `TaskService.update()` — при обновлении вызвать `courseService.syncTaskCourses(id, request.getCourseIds(), teacherId)`

## Верификация

1. **Создание задания:** создать задание → выбрать курсы в форме → сабмит → задание появляется в выбранных курсах
2. **Редактирование задания:** открыть edit → курсы предвыбраны → снять курс → сохранить → задание удалено из курса
3. **Просмотр задания:** открыть view → курсы предвыбраны → снять/выбрать → мгновенная синхронизация
4. **Банк заданий (bulk):** выбрать несколько заданий → «Добавить в курс» → попап работает
5. **Удаление старого компонента:** `TaskCoursePopup` (старый) полностью удалён, нигде не используется
