# План: Замена фильтров банка заданий на Single Select

## Контекст

**Текущее состояние:** 5 фильтров используют `ChipsMultiselect` в режиме `single=true` (чипы-кнопки):
- Грамматические типы (id-based)
- Лексические темы (id-based)
- Механика пунктов (enum-based, ID-маппинг)
- Уровень языка CEFR (enum-based, ID-маппинг)
- Экзамен (enum-based, ID-маппинг)

**Остаётся без изменений:**
- Курсы → `CourseSelectMulti` (CreatableMultiSelect)
- Включать смешанные задания → native checkbox

**Цель:** Заменить 5 `ChipsMultiselect` на `BaseSelectSingle` (react-select), добавить опцию «Все» и возможность очистки каждого фильтра. Добавить глобальную кнопку «Сбросить всё».

## Файлы для изменения

### 2.6. Убрать prop `manageTo` из фильтров — кнопки «+» убрать

**Важно:** пользователь сказал «оставить» кнопки «+». Но `BaseSelectSingle` не поддерживает `manageTo`. Нужно либо:
- Добавить кнопку «+» рядом с селектором (аналогично ChipsMultiselect),
- Либо оставить `manageTo` как отдельный prop и рендерить кнопку.

**Решение:** добавить в `TasksBankFiltersProps` два опциональных prop:
```ts
manageGrammarTypesTo?: '/tasks-bank/grammar-types';
manageTopicsTo?: '/tasks-bank/topics';
```

И рендерить `BasePlusButtonLink` рядом с соответствующими селекторами, используя flexbox row (как было в ChipsMultiselect).

## Верификация

1. **`npm run build`** — нет ошибок компиляции.
2. **Каждый из 5 фильтров:**
   - Открывается как стандартный react-select dropdown
   - Показывает «Все X» как первую опцию
   - Крестик × очищает фильтр (сбрасывает в null)
   - Выбор элемента применяет фильтр, сбрасывает пагинацию на 0
3. **Кнопка «Сбросить всё»:**
   - Сбрасывает все 5 фильтров + курсы
   - Сбрасывает пагинацию
4. **Кнопки «+»** у тем и грамматических типов — остались.
5. **Курсы** — остались CreatableMultiSelect.
6. **Checkbox «Смешанные задания»** — остался.
