**Файл**: `src/student/hooks/useStudentDashboard.ts`

- Добавить логику фильтрации и сортировки:

```typescript
const now = Date.now();
const fourteenDays = 14 * 24 * 60 * 60 * 1000;

// Block 1: "Нужно сделать" — HIGH priority
const block1 = assignments
  .filter(a =>
    (a.status === 'ASSIGNED' || a.status === 'IN_PROGRESS') &&
    a.deadline &&
    (() => { const d = new Date(a.deadline).getTime(); return d >= now && d <= now + fourteenDays; })()
  )
  .sort((a, b) => new Date(a.deadline!).getTime() - new Date(b.deadline!).getTime());

// Block 2: "Новые задания" — LOW priority
const block2 = assignments
  .filter(a => {
    if (a.status !== 'ASSIGNED') return false;
    if (!a.deadline || !a.assignedAt) return false;
    const deadline = new Date(a.deadline).getTime();
    const assigned = new Date(a.assignedAt).getTime();
    const fourteenDaysMs = 14 * 24 * 60 * 60 * 1000;
    const now = Date.now();
    // assignedAt within last 14 days
    if (assigned < now - fourteenDaysMs) return false;
    // deadline more than 14 days away (no overlap with Block 1)
    if (deadline <= now + fourteenDaysMs) return false;
    return true;
  })
  .sort((a, b) => new Date(b.assignedAt).getTime() - new Date(a.assignedAt).getTime());

return { block1, block2, isLoading, isError, error };
```

## Верификация

1. **Block 1**: Задания со статусом `ASSIGNED`/`IN_PROGRESS` и дедлайном ≤ 14 дней отображаются в блоке «Нужно сделать», отсортированы по возрастанию дедлайна
2. **Block 2**: Задания со статусом `ASSIGNED`, созданные ≤ 14 дней назад, с дедлайном > 14 дней — в блоке «Новые задания», отсортированы по убыванию `assignedAt`
3. **Нет пересечений**: Задание не может быть в обоих блоках одновременно
4. **Скрытые**: `COMPLETED` и `EXPIRED` не отображаются нигде на дашборде
5. **Бейджи**: `IN_PROGRESS` → «В процессе», `ASSIGNED` с дедлайном ≤ 7 дней → «Скоро дедлайн» (красный), `ASSIGNED` с дедлайном > 7 дней → «Новое»
6. **Empty state**: При отсутствии заданий в обоих блоках — показывается «На этой неделе всё под контролем 🎉»
7. **Header**: Счётчик в приветствии = `block1.length + block2.length`
8. **Сборка**: `npm run build` проходит без ошибок
