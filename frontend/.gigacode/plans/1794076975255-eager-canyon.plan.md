# Рефакторинг DateTimePicker в TaskAssignPopup

## Цель
Заменить MUI DateTimePicker (на dayjs) на react-day-picker + native `<input type="time">` в TaskAssignPopup.

## Решения
- **Пакет**: `react-day-picker` + `date-fns` (вместо MUI x-date-pickers + dayjs)
- **Время**: нативный `<input type="time">` HTML5
- **Формат**: строка `YYYY-MM-DDTHH:mm` (datetime-local) — без изменений
- **dayjs**: полностью удалить из проекта

## Файлы для изменения

| Файл | Действие |
|------|----------|
| `package.json` | Добавить `react-day-picker`, `date-fns`; удалить `dayjs` |
| `src/shared/ui-kit/DatePicker/DatePicker.tsx` | **Создать** — новый компонент на react-day-picker |
| `src/shared/ui-kit/DatePicker/DatePicker.module.scss` | **Создать** — стили нового пикера |
| `src/tasks/ui/widgets/TaskAssignPopup/TaskAssignPopup.tsx` | Заменить DateTimePicker на DatePicker + TimePicker |
| `src/shared/ui-kit/DateTimePicker/DateTimePicker.tsx` | **Удалить** |
| `src/shared/ui-kit/DateTimePicker/DateTimePicker.module.scss` | **Удалить** |
| `src/shared/ui-kit/DateTimePicker/muiTheme.ts` | **Удалить** |

## Этапы (отдельные коммиты)

### Коммит 1: Установка зависимостей
```bash
npm install react-day-picker date-fns
npm uninstall dayjs @mui/material @mui/x-date-pickers @emotion/react @emotion/styled
```
- `package.json`: добавить `react-day-picker`, `date-fns`
- `package.json`: удалить `dayjs`, `@mui/material`, `@mui/x-date-pickers`, `@emotion/react`, `@emotion/styled`
- `package-lock.json` обновится автоматически

### Коммит 2: Создание нового DatePicker
- Создать `src/shared/ui-kit/DatePicker/DatePicker.tsx`
  - Обёртка над `react-day-picker` (Component mode)
  - Поддержка русского языка (`locales` из `date-fns/locale/ru`)
  - Формат отображения: `DD.MM.YYYY`
  - Внутреннее значение: `Date | null`
  - Внешний API: `value: string` (datetime-local format), `onChange: (v: string) => void`
  - Конвертация: `string → Date` / `Date → string`
  - Тёмная тема через CSS (color-scheme: dark)
- Создать `src/shared/ui-kit/DatePicker/DatePicker.module.scss`
  - Стили поля ввода (рамок, фокус — фиолетовый `#9D7CF2`)
  - Стили выбранной даты (акцентный фон)
  - Календарная сетка (тёмный фон, стили ячеек)

### Коммит 3: Создание TimePicker
- Создать `src/shared/ui-kit/TimePicker/TimePicker.tsx`
  - Нативный `<input type="time">`
  - Формат: `HH:mm` (соответствует datetime-local)
  - Стили: тёмная тема, фиолетовый фокус
- Создать `src/shared/ui-kit/TimePicker/TimePicker.module.scss`

### Коммит 4: Интеграция в TaskAssignPopup
- Заменить `<DateTimePicker>` на `<DatePicker>` + `<TimePicker>`
- `deadline` state: разделить на `deadlineDate` и `deadlineTime`
- При сабмите: объединить в `YYYY-MM-DDTHH:mm`
- UI: два отдельных поля под чекбоксами учеников

### Коммит 5: Очистка
- Удалить `src/shared/ui-kit/DateTimePicker/` (все 3 файла)
- Проверить, что нигде нет импортов из удалённого DateTimePicker

## Зависимости между этапами
1 → 2 → 3 → 4 → 5 (последовательно)

## Верификация
1. `npm run build` — без ошибок TypeScript и сборки
2. Открыть TaskAssignPopup (через "Назначить ученику" в TaskDetailView или bulk-выбор в TasksBankView)
3. Проверить:
   - DatePicker показывает календарь, выбор даты корректен
   - TimePicker показывает время, выбор времени корректен
   - Комбинация даты и времени сохраняется
   - Тёмная тема отображается корректно
   - Нет конфликтов стилей с Radix-модалкой
